What PUMA Analyzer does

Built for thin-film and optical-materials researchers, graduate students processing spectrophotometer data, and QC technicians who need a thickness/n/k number they can trust.

Envelope & Fringe Analysis

Automatic detection of interference extrema and a fit-free cross-check of the film's refractive-index dispersion, following the standard Swanepoel formalism.

Multi-Start Global Fitting

A robust, multi-start nonlinear optimizer refines thickness and dispersion parameters against the full measured spectrum, not just envelope points.

Physics-Guided Auto-Configure

Sensible starting parameters and bounds are derived from the data itself, so a new user isn't left guessing initial guesses for a nonlinear fit.

Classic + Advanced Workflows

From a single-run estimate to Monte Carlo / bootstrap / Bayesian uncertainty analysis, batch processing, and full report/figure export.

How the core engine works

The numerical core (puma_seq.exe, compiled from puma_seq.c) solves an inverse problem: given a measured transmittance spectrum, recover the film thickness and optical constants that produced it. It implements the unconstrained-optimization formulation of Birgin, Chambouleyron & Martínez, credited directly in the engine's own source header.

The physical model

For a thin absorbing film on a transparent substrate at normal incidence:

\[ T(\lambda) = \frac{A\,x}{B - C\,x\cos\varphi + D\,x^{2}} \]
\[ x = e^{-\alpha d}, \qquad \alpha = \frac{4\pi k}{\lambda}, \qquad \varphi = \frac{4\pi n d}{\lambda} \]

The fitting objective

Minimized via multi-start global optimization (reported as the Quadratic Error, QE):

\[ F(n,k,d) = \sum_i \Big[T_{\text{obs}}(\lambda_i) - T_{\text{model}}(\lambda_i;n,k,d)\Big]^2 \]

Tauc band gap

\[(\alpha E)^{r}=B(E-E_g)\]

r=2 direct, r=1/2 indirect.

Urbach energy

\[\alpha(E)=\alpha_0 e^{E/E_u}\]

Disorder-related exponential tail.

Wemple-DiDomenico

\[n^2(E)-1=\frac{E_0 E_d}{E_0^2-E^2}\]

Single-oscillator dispersion.

Frequently asked questions

Why does PUMA need a serial/activation code?

The activation gate protects the project as a scientific tool developed and maintained by one person: it is not a subscription or a commercial-license mechanism, just access control.

Is PUMA open source?

No. The release binaries and update manifest in this repository are public, but the application's source code is maintained in a private repository.

Does PUMA send my measurement data anywhere?

No. Fitting and analysis run entirely locally. The only network calls are the one-time activation check and the startup update check; neither transmits spectra or project data.

Why is the engine a compiled C program instead of pure Python?

puma_seq.c is a long-vetted, scientifically-validated numerical core; recompiling it with a different toolchain has been shown to shift results at the margins, so the shipped binary is pinned and hash-verified rather than rebuilt on each machine.
